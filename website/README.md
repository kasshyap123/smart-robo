# Smart Robo

Animated CAD robot showroom and browser control-panel demo. This export contains the latest locally approved website, including the silver robot with four wheels and one OLED, expressive introduction, scroll-driven part separation without robot rotation, floating part cards, and updated controls.

## Run locally

On macOS, double-click **Open Smart Robo.command** with Python 3 installed. Keep its Terminal window open while browsing.

Alternatively, with Python 3:

```sh
python3 scripts/local-preview.py
```

The launcher prepares the website and opens the browser. Do not open index.html directly: the 3D model needs an HTTP server.

## Build and check

With Node.js installed:

```sh
npm ci
npm run build
npm test
```

To serve the built website:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Then visit http://127.0.0.1:4173 .

## Included files

- `index.html`, `app.js`, `style.css`: latest showroom.
- `controls/`: driving simulation, expressions, scripted conversation, routines and settings.
- `assets/`: CAD-derived model buffers and geometry metadata.
- `source-cad/`: STEP sources, CAD scripts, and structural assembly data.
- `vendor/`: local Three.js runtime and licence.
- `scripts/`: build, local launcher, geometry conversion and verification.
- `dist/`: ready-to-serve copy; regenerated by the build and ignored by Git.
- `vercel.json`: existing static deployment configuration.
- Icons, service workers and web manifests for the website.

## Repository location

This website is included under `website/` in the Smart Robo repository. The
hardware development source and project overview are in the parent directory.
Local hosting-account metadata, original deployment shortcuts, generated `dist/`,
duplicate website history, QA records, and CAD validation-result records were omitted from this repository copy.

## Current limits

Controls are an offline browser simulation. Live robot communication, AI conversation, voice processing and backend storage have not been implemented. Source CAD remains marked HOLD; this showroom is not a manufacturing approval. Visual wheel/OLED embellishments and animation do not certify physical fit.

The current overview above describes the included website; older archived website descriptions remain in the original local export.
